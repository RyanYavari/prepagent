# PrepAgent

## What this is
AI-powered interview research tool. Users sign in with Google, enter a company + interviewer, and receive a 4-section briefing generated by a LangGraph multi-agent pipeline in under 90 seconds.

## Stack
- **Backend:** Python 3.12, FastAPI, LangGraph, LangChain, Claude Sonnet
- **Frontend:** Next.js (app router), TypeScript, Tailwind, Supabase SSR
- **Database:** Supabase PostgreSQL + pgvector
- **Evals:** RAGAS (faithfulness, relevance, context precision)
- **Observability:** LangSmith tracing on every agent step
- **Auth:** Google OAuth via FastAPI backend (JWT sessions)
- **CI:** GitHub Actions (ruff, pytest, typecheck)

## Architecture (fixed DAG, not supervisor)
Company Intelligence + Interviewer Research run in parallel, then RAG Retrieval, then Synthesis. Fixed edges, no supervisor. See ARCHITECTURE_DECISIONS.md for reasoning.

## Code conventions
- Pydantic models for all request/response schemas (backend/models/)
- FastAPI dependency injection for auth (backend/dependencies/auth.py)
- Identity always from JWT token, never from request body
- All agent nodes in backend/agents/, services in backend/services/
- Environment variables in .env, never hardcoded
- Conventional commits: feat:, fix:, refactor:, test:, docs:, chore:

## Non-obvious gotchas
- Google OAuth tokens stored in Supabase users table, not in session
- pgvector chosen over Pinecone (corpus is too small for dedicated vector service)
- Frontend auth state lives in localStorage (session JWT)
