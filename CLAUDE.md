
# PrepAgent

## What this is
An AI-powered interview research tool. Users sign in with Google, upload their resume, enter a company name and interviewer, and receive a personalized 4-section briefing in 90 seconds generated by a LangGraph multi-agent pipeline.

## Tech Stack
- Frontend: Next.js (app router), TypeScript, Tailwind, Supabase SSR
- Backend: FastAPI, Python 3.12, LangGraph, LangChain, Claude Sonnet
- Database: Supabase PostgreSQL
- Vector store: Pinecone
- Reranking: Cohere
- Observability: LangSmith
- Evals: RAGAS
- Auth: Google OAuth via FastAPI backend
- MCP: Gmail, Google Calendar, Google Drive

## Current State (End of Day 1)
- FastAPI backend running with /health endpoint
- Next.js frontend running with placeholder landing page
- Supabase project created with 4 tables: users, briefings, research_runs, gmail_watches
- Google Cloud Console app created with Gmail, Calendar, Drive APIs enabled
- OAuth consent screen configured, submitted for verification
- All environment variables filled in

## Day 2 Goal
Implement Google OAuth flow so users can sign in with Google and land on a dashboard.

### Exactly what needs to be built:

**Backend (FastAPI):**
1. `backend/routers/auth.py` -- two endpoints:
   - `GET /auth/google` -- generates Google OAuth URL and returns it
   - `GET /auth/callback` -- receives the OAuth code from Google, exchanges it for access + refresh tokens, upserts user in Supabase users table, returns a session token to the frontend
2. `backend/services/google_auth.py` -- helper functions for token exchange and refresh using google-auth-oauthlib

**Frontend (Next.js):**
1. Update `frontend/app/page.tsx` -- Sign in with Google button calls `GET /auth/google` from the FastAPI backend and redirects user to the returned Google OAuth URL
2. Create `frontend/app/auth/callback/page.tsx` -- handles the OAuth redirect from Google, sends the code to FastAPI `GET /auth/callback`, stores the returned session token, redirects to /dashboard
3. Create `frontend/app/dashboard/page.tsx` -- protected page, shows "Welcome [email]" and an empty briefing history for now. Redirects to / if not authenticated.
